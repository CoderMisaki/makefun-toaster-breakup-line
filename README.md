# Unplugged: A Smart Toaster's Breakup Line

Entry for the make.fun competition
`u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92`.

`main.py` (Python 3.13, standard library only, no network) writes one
original breakup line from a newly self-aware smart toaster to
`/output/entry.txt`. The program is deterministic: every run produces the
same bytes.

Run it:

```sh
python3 main.py
```
